# THE FACE — sculpted stone tables

Եռալեզու (հայերեն / ռուսերեն / անգլերեն) կայք՝ կատալոգով, անհատական պատվերի
կոնֆիգուրատորով և ադմին վահանակով, որտեղ նոր ապրանքն ավելացվում է առանց ծրագրավորողի։

Stack: **Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · Supabase**

---

## 1. Տեղային գործարկում (5 րոպե)

```bash
npm install
cp .env.example .env.local     # Windows: copy .env.example .env.local
npm run dev
```

Բացեք http://localhost:3000

> Առանց Supabase-ի կայքը միևնույն է աշխատում է՝ ցուցադրելով 4 demo ապրանք,
> որպեսզի կարողանաք անմիջապես տեսնել դիզայնը։

---

## 2. Supabase-ի միացում (ադմինկան և իրական կատալոգը)

1. Գրանցվեք https://supabase.com → **New project** (Region: Frankfurt կամ մոտակա)։
2. **SQL Editor → New query** → պատճենեք `supabase/schema.sql`-ի ամբողջ պարունակությունը → **Run**։
   Սա ստեղծում է `products` և `inquiries` աղյուսակները, անվտանգության
   կանոնները (RLS) և `product-images` storage bucket-ը։
3. **Project Settings → API** → պատճենեք.
   - `Project URL` → `NEXT_PUBLIC_SUPABASE_URL`
   - `anon public` key → `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   և տեղադրեք `.env.local` ֆայլում։
4. **Authentication → Users → Add user** → ձեր email + գաղտնաբառ
   (միացրեք *Auto Confirm User*)։ Սա ձեր ադմին մուտքն է։
5. **Authentication → Providers → Email** → անջատեք **Enable sign-ups**,
   որպեսզի ուրիշները չկարողանան գրանցվել։
6. Վերագործարկեք `npm run dev`։

Ադմինկան՝ http://localhost:3000/admin

---

## 3. Ինչպես ավելացնել ապրանք

`/admin` → **+ Նոր ապրանք** →

- քաշեք նկարները (առաջինը՝ գլխավորը, սլաքներով փոխեք հերթականությունը),
- լրացրեք անվանումն ու նկարագրությունը 3 լեզվով (ռուսերենն ու անգլերենը
  ոչ պարտադիր են — դատարկ լինելու դեպքում ցուցադրվում է հայերենը),
- **Գին** դաշտը դատարկ թողնելով՝ կայքում կգրվի «Գինը՝ հարցումով»,
- **Ցուցադրել գլխավոր էջում** → ապրանքը հայտնվում է գլխավոր էջի «Ընտրված գործեր» բաժնում,
- **Պահպանել**։

Ապրանքն անմիջապես հայտնվում է կատալոգում՝ բոլոր երեք լեզուներով։

`/admin/inquiries` — կայքից եկած բոլոր հարցումները (ապրանք, անհատական պատվեր, կապ),
կարգավիճակներով՝ Նոր / Ընթացքում / Փակված։

## 4. Հրապարակում Vercel-ում

1. Կոդը վերբեռնեք GitHub-ում (նոր private repo)։
2. https://vercel.com → **Add New → Project** → ընտրեք repo-ն։
3. **Environment Variables** բաժնում ավելացրեք `.env.example`-ի բոլոր փոփոխականները
   (իրական արժեքներով, `NEXT_PUBLIC_SITE_URL`-ը՝ ձեր դոմենը)։
4. **Deploy**։
5. Դոմեն միացնելու համար՝ **Settings → Domains → Add** և ձեր ռեգիստրատորում
   ուղղեք DNS-ը Vercel-ի ցուցումների համաձայն։

## 5. Կառուցվածք

```
src/
  app/
    [locale]/            # հանրային կայքը (hy | ru | en)
      page.tsx           # գլխավոր
      catalog/           # կատալոգ + ապրանքի էջ
      custom/            # անհատական պատվերի կոնֆիգուրատոր
      story/  contact/
    admin/               # ադմին վահանակ (փակ է middleware-ով)
    api/inquiries/       # հարցումների ընդունում
  components/            # UI բաղադրիչներ
  i18n/                  # hy.ts / ru.ts / en.ts — կայքի ամբողջ տեքստը
  lib/                   # Supabase, ապրանքների տվյալներ, կոնտակտներ
supabase/schema.sql      # բազայի սխեման
```

**Տեքստ փոխելու համար** խմբագրեք `src/i18n/hy.ts`, `ru.ts`, `en.ts` —
երեքն ունեն նույն կառուցվածքը։

**Գույներն ու տառատեսակները**՝ `src/app/globals.css`, `@theme` բլոկում։

**Կոնտակտները** (հեռախոս, WhatsApp, email, Instagram) գալիս են `.env.local`-ից։

## 6. Անվտանգություն

- `/admin`-ը փակ է `src/middleware.ts`-ով — առանց մուտքի վերահղում է `/admin/login`։
- Բազայում RLS-ը թույլ է տալիս անանուն այցելուին միայն **կարդալ հրապարակված ապրանքները**
  և **ուղարկել հարցում**։ Խմբագրելն ու հարցումները կարդալը՝ միայն մուտք գործած օգտատիրոջ։
- `anon` բանալին հրապարակային է ըստ նախագծման — վտանգավոր չէ։
  `service_role` բանալին **երբեք** մի՛ դրեք կայքի կոդում։
