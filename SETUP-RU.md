# THE FACE — запуск сайта

Всё по шагам. Порядок важен: сначала база (Supabase), потом деплой (Vercel), потом домен.

---

## 0. Локально посмотреть сайт

```bash
npm install
npm run dev
```

→ http://localhost:3000

Пока Supabase не подключён, сайт показывает 4 демо-товара с вашими фото —
чтобы можно было сразу видеть дизайн. Как только подключите базу, сайт берёт
товары из неё.

---

## 1. Supabase (база + админка) — 10 минут

1. https://supabase.com → зарегистрироваться → **New project**.
   Region: **Frankfurt** (ближайший к Армении). Пароль базы сохраните себе.
2. Слева **SQL Editor → New query** → скопировать туда **весь** файл
   `supabase/schema.sql` из проекта → **Run**.
   Это создаёт таблицы `products` и `inquiries`, правила безопасности
   и хранилище для фото `product-images`.
   Затем так же выполнить `supabase/migration-02.sql` — он добавляет
   категории и настройки сайта, которыми управляет админка.
3. **Project Settings → API** → скопировать два значения:
   - `Project URL` → в `.env.local` в строку `NEXT_PUBLIC_SUPABASE_URL=`
   - `anon public` ключ → в `NEXT_PUBLIC_SUPABASE_ANON_KEY=`
4. **Authentication → Users → Add user** → ваш email + пароль,
   включить галочку **Auto Confirm User**. Это ваш вход в админку.
5. **Authentication → Sign In / Providers → Email**. Здесь два разных
   переключателя, не перепутайте:
   - **Enable Email provider** — должен быть **ВКЛЮЧЁН**. Это сам вход по почте;
     если выключить, на входе будет ошибка «Email logins are disabled».
   - **Allow new users to sign up** — **ВЫКЛЮЧИТЬ**, чтобы посторонние
     не могли зарегистрироваться.
6. Перезапустить `npm run dev`.

Админка: http://localhost:3000/admin

## 2. Как добавить товар

`/admin` → **+ Новый товар** →

- перетащить фото (первое фото = главное, стрелками меняется порядок),
- **Название** по-русски обязательно, армянский и английский — по желанию
  (если пусто, покажется русское),
- **Цена** пустая = на сайте будет «цена по запросу»,
- галочка **Показывать на главной** — товар попадёт в блок «Избранные работы»,
- **Сохранить**.

Товар сразу появляется в каталоге на всех трёх языках.

Заявки с сайта (товар / индивидуальный заказ / контакты) — `/admin/inquiries`,
со статусами Новая / В работе / Закрыта.

## 3. Домен theface.am

Регистраторы армянской зоны: **abcdomain.am**, **internet.am** (ISOC.am).
Покупаете домен — DNS настроите на шаге 4, после деплоя.

---

## 4. Деплой на Vercel (бесплатно)

1. Загрузить папку `theface` в новый **приватный** репозиторий на GitHub.
2. https://vercel.com → войти через GitHub → **Add New → Project** → выбрать репозиторий.
3. В разделе **Environment Variables** добавить (значения — свои):

   ```
   NEXT_PUBLIC_SUPABASE_URL
   NEXT_PUBLIC_SUPABASE_ANON_KEY
   NEXT_PUBLIC_PHONE
   NEXT_PUBLIC_WHATSAPP
   NEXT_PUBLIC_EMAIL
   NEXT_PUBLIC_INSTAGRAM
   NEXT_PUBLIC_SITE_URL      → https://theface.am
   ```

4. **Deploy**.
5. **Settings → Domains → Add** → `theface.am` → Vercel покажет, какие DNS-записи
   прописать у регистратора (обычно A-запись на `76.76.21.21` и CNAME `www`).
   После обновления DNS (от 15 минут до нескольких часов) сайт откроется на домене.

## 5. Что где менять

| Что | Где |
|---|---|
| Тексты сайта (все 3 языка) | `src/i18n/ru.ts`, `hy.ts`, `en.ts` |
| Цвета и шрифты | `src/app/globals.css`, блок `@theme` |
| Телефон, WhatsApp, email, Instagram | переменные окружения (`.env.local` и Vercel) |
| Фото на главной, в «Истории», в «Индивидуальном заказе» | `public/media/`, пути прописаны в страницах |
| Товары | только через админку |

---

## 6. Безопасность

- `/admin` закрыт: без входа перекидывает на `/admin/login`.
- В базе анонимный посетитель может только **читать опубликованные товары**
  и **оставить заявку**. Редактировать и читать заявки — только вы после входа.
- Ключ `anon` публичный по замыслу, это не утечка.
  Ключ `service_role` **никогда** не вставляйте в код сайта.
